# ADR-004. 재검색 상한과 미답변 정책

- 상태: 채택
- 날짜: 2026-09-08

## 맥락

자기교정 루프는 "부족하면 다시 검색한다"인데, 근거가 애초에 없는 질문에서는 이 루프가
끝나지 않는다. 재검색 한 번은 임베딩 1회 + 리랭킹 1회 + LLM 판정 1회다. 상한이 없으면
비용과 지연이 질문 하나에서 선형으로 늘어난다.

더 중요한 문제. 금융 답변에서 **틀린 답은 답이 없는 것보다 나쁘다.** 해지환급금처럼
약관에 없는 값을 물으면 "산출방법서 영역"이라고 답해야 하는데, 루프를 오래 돌리면
모델이 결국 그럴듯한 숫자를 만들어 낸다.

## 결정

1. 재검색 상한 `MAX_RETRIES=2`. 상한에 닿으면 **근거의 한계를 명시한 답변**으로 간다.
2. `grade` 판정이 `none` 이면 재검색하지 않고 바로 거절한다.
3. 거절 문구를 코드가 아니라 `agent/policy.yaml` 에 둔다. 고객 대면 문구라 바뀐다.
4. 거절 유형을 나눈다: 근거 없음 / 근거 부족 / 문서 밖(산출방법서) / 파라미터 없음 /
   개인정보 / 실행 불가.
5. `policy_version` 을 응답과 감사 로그에 싣는다. "그때 어떤 정책이었나"를 재구성한다.
6. 에스컬레이션 트리거(민원·분쟁·소송·해지환급금 등)에 걸리면 답변과 함께 상담 연결을 안내한다.

## 근거

지표를 두 개로 나눠 본다.

- **미답변 정확도**: 거절해야 할 질문을 실제로 거절했는가
- **오거절률**: 답할 근거가 있는데 거절했는가

하나만 보면 속는다. 전부 거절하면 미답변 정확도는 100% 가 된다. 둘을 같이 봐야
"상한 2"가 맞는 값인지 판단할 수 있다. `eval/metrics.py` 가 둘 다 계산한다.

## 결과

- 상한은 `.env` 에서 바꾼다. 6회차에서 1·2·3 을 비교해 오거절률 변화를 본다.
- 계산 노드는 필수 파라미터가 없으면 계산하지 않고 `missing_parameter` 로 분기한다.
  하나은행 2014 설명서의 `( )%` 빈칸이 그 경로를 타는 실물이다.
