# ADR — 설계 결정 기록

`docs/templates/adr.md` 를 복사해서 `ADR-00N-<이름>.md` 로 채웁니다. 완성 예시는 `docs/session2/examples/01_ADR-001_청킹_전략.md`, `docs/session3/examples/01_ADR-002_인제스천_그래프.md`, `docs/session4/examples/01_ADR-003_Hybrid_검색.md` 에 있습니다. 5회차의 `ADR-004-agent-policy.md`(재검색 상한과 미답변 정책)는 강사가 쓴 완성본이고, 5회차 과제는 ADR 이 아니라 에이전트 정책 1쪽(`docs/templates/agent_policy.md` → `docs/agent_policy.md`)입니다.
